Вспоминаем прошлое занятие

1. Чем отличаются justify-content и align-items?

justify-content раскладывает элементы вдоль главной оси, align-items выравнивает их по поперечной оси.

2. Что станет главной осью при flex-direction: column и что тогда сделает justify-content: center?

Главная ось идёт сверху вниз. justify-content: center поставит элементы в середину по вертикали (если у контейнера есть высота).

3. Почему для промежутков между элементами удобнее gap, а не margin?

gap ставит отступ только между элементами: не нужно убирать лишний отступ у последнего.

Типичный неверный ответ на вопрос 1: «justify-content — по горизонтали, align-items — по вертикали». Это верно только для ряда. Спросите: а если column?

Как элементы делят место

В этом блоке ты научишься решать, какой элемент растягивается, какой не сжимается и с какого размера элемент начинает.

01
Правило Блок 1 · Как элементы делят место

Что такое свободное место

Свободное место — часть контейнера по главной оси, которую элементы не заняли.

Считаем

  • Контейнер: 320px.
  • Элементы: 3 × 64 = 192px.
  • Свободно: 320 − 192 = 128px — пустота справа.

Похоже на парту на троих, где все сели у левого края.

По умолчанию свободное место остаётся пустым: элементы его не забирают.
Правило Блок 1 · Как элементы делят место

flex-grow — забрать свободное место

Доля свободного места, которую забирает элемент. По умолчанию 0.

Сверху без flex-grow, снизу с ним. Пишется элементу.
Блок 1 · Как элементы делят место

Числа у flex-grow — это доли остатка

Разбор

  1. Свободно: 320 − 3 × 64 = 128px.
  2. Долей всего: 1 + 2 + 1 = 4, одна доля = 32px.
  3. Крайние: 64 + 32 = 96px.
  4. Средний: 64 + 2 × 32 = 128px.

Рамка 1px прибавляется к каждому, поэтому на глаз чуть больше.

Делится только свободное место, а не вся ширина контейнера.
! Ловушка Блок 1

flex-grow: 2 — не значит «в 2 раза шире»

Почему

Каждый элемент начинает со своей ширины по тексту, и только остаток делится 1 : 2. Длинный текст уже занял много места, остаток маленький. Чтобы делить всю ширину, стартовый размер должен быть одинаковым — это flex-basis, он через 2 слайда.

Попросите учеников предсказать результат до того, как посмотрят в окно. Большинство скажет «вторая вдвое шире». На деле вторая шире, но не вдвое: стартовые ширины разные.
Правило Блок 1 · Как элементы делят место

flex-shrink — сжиматься, когда места мало

Когда места мало, элементы сжимаются. flex-shrink: 0 — не сжиматься.

Сверху сжались все, снизу логотип остался 160px.
Правило Блок 1 · Как элементы делят место

flex-basis — стартовый размер по главной оси

Браузер сначала ставит элементы по flex-basis, потом делит остаток. В ряду это ширина, в колонке — высота.

flex-basis — размер вдоль главной оси; width — всегда ширина.

✓ Вопросы Блок 1 · 5 минут

Проверь себя перед практикой

1. Контейнер 500px, три элемента по width: 100px, у них flex-grow 1, 3 и 1. Какой ширины будут элементы?

Свободно 200px, долей 5, одна доля 40px. Ширины: 140, 220 и 140px.

2. Почему круглый аватар стал овалом на узком экране и как это исправить?

По умолчанию flex-shrink: 1: при нехватке места сжимается и аватар. Исправление — flex-shrink: 0 у аватара.

3. Чем flex-basis: 96px отличается от width: 96px?

flex-basis — размер вдоль главной оси: в колонке это высота. width — всегда ширина.

4. Найди ошибку: .search-row { display: flex; flex-grow: 1; } — поле поиска не растягивается.

flex-grow написан контейнеру. Его нужно писать элементу: .search-row input { flex-grow: 1; }.

Типичные неверные ответы: 1 — «100, 300, 100» (делят всю ширину, а не остаток); 2 — «увеличить width аватару».

! Ловушка Блок 2

Одинокая карточка на всю ширину

Почему

Свободное место делится в каждой строке отдельно: у верхнего блока во второй строке карточка одна, всё место — ей. Карточкам в сетке обычно хватает flex-basis.

Спросите, пока смотрите только код: что будет с четвёртой карточкой? Обычно отвечают «встанет под первой такого же размера».
Правило Блок 2 · Один элемент

align-self — свой порядок для одного элемента

align-self выравнивает один элемент по поперечной оси. Значения те же, что у align-items.

По умолчанию align-items: stretch: «Кружок» вытянулся до высоты соседа. «Объявление» с align-self: flex-start прижато к верху. align-self у элемента сильнее align-items у контейнера.
Правило Блок 2 · Один элемент

Что работает, а что нет

Работает

  • align-self: flex-end;у элемента flex-контейнера: прижат к концу поперечной оси
  • align-self: center; при flex-direction: columnв колонке поперечная ось горизонтальная: элемент встанет по центру по ширине
  • flex-wrap: wrap; у контейнераперенос включается у родителя

Не работает

  • align-self у элемента, родитель которого не flexбраузер пропустит свойство
  • align-self: flex-end;, чтобы сдвинуть элемент вправо в рядуэто главная ось, align-self ей не управляет
  • flex-wrap: wrap; у карточкиу элемента перенос ничего не меняет
align-self двигает элемент только по поперечной оси.
✓ Вопросы Блок 2 · 3 минуты

Проверь себя перед практикой

1. Контейнер 500px с flex-wrap: wrap и gap: 16px, в нём карточки flex-basis: 200px. Сколько карточек в первой строке?

Две: 200 + 16 + 200 = 416px. Третья потребует ещё 216px, это уже 632px.

2. Почему последняя карточка растянулась на всю строку?

У карточек flex-grow: 1, а свободное место делится в каждой строке отдельно. В последней строке карточка одна.

3. Можно ли через align-self прижать одну кнопку к правому краю ряда?

Нет: в ряду правый край — главная ось, а align-self работает по поперечной.

Типичный неверный ответ на вопрос 1: «две с половиной» или «три». Напомните: карточка не режется, она переносится целиком.

Вопросы по всей теме 2.5

1. Что будет, если в «Кружках школы» поменять flex-wrap: wrap на nowrap?

Все карточки встанут в одну строку и сожмутся уже 200px: по умолчанию flex-shrink: 1.

2. У карточки flex-basis: 200px и padding: 16px. Какой она будет ширины без box-sizing: border-box (тема 2.3)?

232px: стартовый размер относится к содержимому, и отступы прибавляются. С border-box — ровно 200px.

3. Бейдж «Хит» в углу обложки поверх картинки — это position: absolute (тема 2.4) или align-self?

Поверх другого элемента — position: absolute. align-self выравнивает элемент среди соседей, он остаётся в общем потоке.

Типичный неверный ответ на вопрос 1: «карточки вылезут за край». Вылезут только те, что не могут сжаться, например с flex-shrink: 0.

  • Без @media — только свойства этой темы.
Идея решения: flex-wrap: wrap у шапки, у поиска flex-basis (например, 200px) и flex-grow: 1. Когда поиску не хватает его стартового размера, он переносится и растягивается на свою строку.
